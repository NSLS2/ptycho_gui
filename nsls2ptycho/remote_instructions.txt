1. Login to a computation node that 1) has access to the /nsls2/data/ file system and 2) have CUDA compatible GPU cards for the recon task.
2. Switch to the ptycho/ directory which has the scan_XXXXXX.h5 header files.
3. Do 'python -m nsls2ptycho.remote_worker' and it will start monitoring the communication path like 'remote_<srvname>'
4. Create the task config file inside the monitored communication path 'remote_<srvname>/', either from GUI or from copying a previous config file.
5. The remote worker should grab the config file and start running the reconstruction.
6. If started from GUI, the intermediate results and reconstruction messages should be sent back to GUI through temporary files inside remote_<srvname>/
